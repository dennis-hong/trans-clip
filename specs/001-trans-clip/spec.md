# Feature Specification: TransClip - 번역 및 클립보드 관리 앱

**Feature Branch**: `001-trans-clip`
**Created**: 2025-12-30
**Status**: Draft
**Input**: User description: "맥북에서 동작하는 DeepL 앱처럼 어디에서든 Cmd+CC(복사 2번)를 누르면 창이 떠서 한글이면 영어로, 영어면 한글로 번역해주고, 복사 버튼을 누르면 클립보드로 번역내용이 복사되고, 바꾸기 버튼을 누르면 해당 드래그했던 자리가 번역된 내용으로 대체되는 번역앱. Claude API를 사용하여 번역. 클립보드 히스토리 관리 기능과 사용자 정의 단어집 기능 포함. 편리한 GUI 제공."

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 빠른 번역 (Priority: P1)

사용자가 맥북에서 작업 중 텍스트를 드래그하여 선택하고, Cmd+C를 두 번 연속으로 누르면 번역 창이 나타납니다. 창에는 원문과 자동 감지된 언어를 기반으로 한 번역문(한글↔영어)이 함께 표시됩니다. 사용자는 번역 결과를 확인하고 필요에 따라 복사하거나 원문을 대체할 수 있습니다.

**Why this priority**: 핵심 기능으로, 사용자가 앱을 사용하는 주된 목적입니다. 한글로 타이핑하고 영어로 일해야 하는 사용자의 일상적인 워크플로우를 직접 지원합니다.

**Independent Test**: 텍스트 선택 후 Cmd+CC를 눌러 번역 창이 나타나고 번역 결과가 표시되는지 확인하여 테스트할 수 있습니다. 이 기능만으로도 기본적인 번역 도구로서 가치를 제공합니다.

**Acceptance Scenarios**:

1. **Given** 사용자가 한글 텍스트를 선택한 상태, **When** Cmd+C를 두 번 연속으로 누름 (500ms 이내), **Then** 번역 팝업 창이 나타나고 원문(한글)과 번역문(영어)이 표시됨
2. **Given** 사용자가 영어 텍스트를 선택한 상태, **When** Cmd+C를 두 번 연속으로 누름, **Then** 번역 팝업 창이 나타나고 원문(영어)과 번역문(한글)이 표시됨
3. **Given** 번역 팝업이 열린 상태, **When** "복사" 버튼 클릭, **Then** 번역된 텍스트가 클립보드에 복사되고 사용자에게 피드백 제공
4. **Given** 텍스트를 선택하고 번역 팝업이 열린 상태, **When** "바꾸기" 버튼 클릭, **Then** 원래 선택했던 위치의 텍스트가 번역된 내용으로 대체됨

---

### User Story 2 - 클립보드 히스토리 관리 (Priority: P2)

사용자가 Cmd+C를 한 번 누를 때마다 복사된 내용이 클립보드 히스토리에 저장됩니다. 사용자는 이전에 복사한 항목들을 목록에서 보고, 원하는 항목을 선택하여 재사용하거나 삭제할 수 있습니다.

**Why this priority**: 번역 기능과 함께 사용하면 시너지 효과가 있으며, 독립적으로도 생산성을 크게 향상시키는 기능입니다. 단순히 번역만 하는 것이 아니라 클립보드 관리까지 제공하여 "일석이조"의 가치를 제공합니다.

**Independent Test**: Cmd+C로 여러 항목을 복사한 후 클립보드 히스토리에서 이전 항목을 선택하여 붙여넣기가 되는지 확인합니다.

**Acceptance Scenarios**:

1. **Given** 앱이 실행 중인 상태, **When** 사용자가 Cmd+C로 텍스트를 복사, **Then** 복사된 내용이 클립보드 히스토리에 추가됨
2. **Given** 클립보드 히스토리에 여러 항목이 있는 상태, **When** 히스토리 목록에서 특정 항목 선택, **Then** 해당 항목이 현재 클립보드에 설정되어 Cmd+V로 붙여넣기 가능
3. **Given** 클립보드 히스토리에 항목이 있는 상태, **When** 특정 항목의 삭제 버튼 클릭, **Then** 해당 항목이 히스토리에서 제거됨
4. **Given** 앱이 재시작된 상태, **When** 클립보드 히스토리 확인, **Then** 이전 세션에서 저장된 항목들이 유지됨

---

### User Story 3 - 사용자 정의 단어집 (Priority: P3)

사용자가 사내에서만 사용하는 전문 용어나 특수 단어를 단어집에 등록하면, 번역 시 해당 용어가 올바르게 번역됩니다. 예를 들어, 회사 제품명이나 내부 프로젝트명 등을 원하는 번역어로 매핑할 수 있습니다.

**Why this priority**: 기본 번역 기능이 동작한 후에 정확도를 높이는 부가 기능입니다. 사내 용어를 정확히 번역하는 것이 중요하지만, 기본 번역 없이는 의미가 없습니다.

**Independent Test**: 단어집에 "회사명 → CompanyName"을 등록한 후, "회사명을 입력하세요"를 번역하면 "Please enter CompanyName"으로 번역되는지 확인합니다.

**Acceptance Scenarios**:

1. **Given** 단어집 관리 화면, **When** 새 단어 쌍(원어, 번역어) 추가, **Then** 단어집에 저장되고 이후 번역에 반영됨
2. **Given** 단어집에 "RFC"="요청서"가 등록된 상태, **When** "RFC를 작성해주세요"를 번역, **Then** "Please write the 요청서"가 아닌 사용자가 정의한 방식으로 번역됨
3. **Given** 단어집에 항목들이 있는 상태, **When** 특정 항목 삭제 또는 수정, **Then** 변경사항이 저장되고 이후 번역에 반영됨

---

### User Story 4 - 편리한 GUI (Priority: P2)

앱은 메뉴바(시스템 트레이)에 상주하며, 직관적인 UI를 통해 번역 결과 확인, 클립보드 히스토리 접근, 단어집 관리, 설정 변경 등을 쉽게 수행할 수 있습니다.

**Why this priority**: 모든 기능에 접근하기 위한 기반 UI입니다. 좋은 UX 없이는 다른 기능들의 가치가 떨어집니다.

**Independent Test**: 메뉴바 아이콘 클릭으로 앱에 접근하고, 각 기능으로 이동할 수 있는지 확인합니다.

**Acceptance Scenarios**:

1. **Given** 앱이 실행된 상태, **When** 메뉴바 아이콘 클릭, **Then** 클립보드 히스토리와 주요 기능에 접근할 수 있는 메뉴/패널 표시
2. **Given** 번역 팝업이 열린 상태, **When** 창 외부 클릭 또는 ESC 키 누름, **Then** 팝업이 닫힘
3. **Given** 설정 화면, **When** Claude API 키 입력 및 저장, **Then** API 키가 안전하게 저장되고 번역 기능 사용 가능

---

### Edge Cases

- 빈 텍스트를 선택하고 Cmd+CC를 누르면 어떻게 되는가? → 에러 메시지나 아무 동작 없이 무시
- 네트워크가 없는 상태에서 번역을 시도하면? → 사용자에게 네트워크 연결 필요 알림 표시
- 매우 긴 텍스트(10,000자 이상)를 번역하려고 하면? → 적절한 길이 제한 안내 또는 청크 단위 처리
- Claude API 키가 유효하지 않으면? → API 키 확인 필요 안내
- 바꾸기 기능 사용 시 원본 앱이 텍스트 입력을 허용하지 않으면? → 실패 알림 및 클립보드에 번역 내용 복사 제안
- 클립보드 히스토리가 가득 차면? → 가장 오래된 항목 자동 삭제 (최대 저장 개수는 설정 가능)
- 이미지나 파일을 복사했을 때? → 클립보드 히스토리에서 텍스트만 저장하거나 파일명/미리보기 저장

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 시스템은 전역 단축키 Cmd+C 두 번 연속 입력(500ms 이내)을 감지하여 번역 팝업을 표시해야 함
- **FR-002**: 시스템은 선택된 텍스트의 언어를 자동 감지하여 한글↔영어 간 번역을 수행해야 함
- **FR-003**: 시스템은 Claude API를 사용하여 번역을 수행해야 함
- **FR-004**: 번역 팝업은 원문과 번역문을 동시에 표시해야 함
- **FR-005**: 사용자는 "복사" 버튼을 통해 번역된 텍스트를 클립보드에 복사할 수 있어야 함
- **FR-006**: 사용자는 "바꾸기" 버튼을 통해 원본 텍스트를 번역된 내용으로 대체할 수 있어야 함
- **FR-007**: 시스템은 Cmd+C로 복사된 모든 텍스트를 클립보드 히스토리에 저장해야 함
- **FR-008**: 사용자는 클립보드 히스토리에서 이전 항목을 선택하여 재사용할 수 있어야 함
- **FR-009**: 사용자는 클립보드 히스토리에서 항목을 삭제할 수 있어야 함
- **FR-010**: 시스템은 사용자 정의 단어집을 지원하여 특정 용어의 번역을 사용자가 정의할 수 있어야 함
- **FR-011**: 단어집은 원어-번역어 쌍으로 구성되며, 추가/수정/삭제가 가능해야 함
- **FR-012**: 번역 시 단어집에 등록된 용어가 우선 적용되어야 함
- **FR-013**: 앱은 macOS 메뉴바에 상주하며 백그라운드에서 실행되어야 함
- **FR-014**: 사용자는 설정에서 Claude API 키를 입력하고 저장할 수 있어야 함
- **FR-015**: API 키는 시스템 키체인 또는 동등한 보안 저장소에 안전하게 저장되어야 함
- **FR-016**: 클립보드 히스토리는 앱 재시작 후에도 유지되어야 함
- **FR-017**: 클립보드 히스토리의 최대 저장 개수는 사용자가 설정할 수 있어야 함 (기본값: 50개)

### Key Entities

- **ClipboardItem**: 클립보드에 복사된 개별 항목. 텍스트 내용, 복사 시간, 출처 앱(선택적) 포함
- **Translation**: 번역 요청 및 결과. 원문, 번역문, 원문 언어, 대상 언어, 번역 시간 포함
- **GlossaryEntry**: 단어집 항목. 원어, 번역어, 생성일, 메모(선택적) 포함
- **UserSettings**: 사용자 설정. API 키, 히스토리 최대 개수, 단축키 설정 등 포함

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: 사용자가 Cmd+CC 입력 후 1초 이내에 번역 팝업이 표시됨
- **SC-002**: 번역 결과가 3초 이내에 표시됨 (일반적인 문장 길이 기준, 200자 이하)
- **SC-003**: 사용자가 3번의 클릭 이내에 클립보드 히스토리의 이전 항목을 재사용할 수 있음
- **SC-004**: 단어집에 등록된 용어가 번역에 100% 반영됨
- **SC-005**: 앱이 백그라운드에서 10MB 이하의 메모리를 사용함 (유휴 상태)
- **SC-006**: 클립보드 히스토리가 앱 재시작 후에도 100% 유지됨
- **SC-007**: "바꾸기" 기능이 텍스트 입력을 지원하는 앱에서 95% 이상 성공률을 보임

## Assumptions

- 사용자는 macOS를 사용함 (다른 OS 지원은 현재 범위에 포함되지 않음)
- 사용자는 유효한 Claude API 키를 가지고 있음
- 인터넷 연결이 번역 기능 사용에 필요함
- "바꾸기" 기능은 macOS의 접근성 API를 통해 구현되며, 사용자가 접근성 권한을 허용해야 함
- 클립보드 히스토리는 텍스트 항목만 저장함 (이미지, 파일 등은 제외)
- Cmd+C 두 번 감지 간격은 500ms로 설정 (향후 사용자 설정 가능)
